2026-09-27 — canvas layout draft loss (defect fix): `loadProject` replaced `project` wholesale whenever the SSE `project.updated` or a reconnect triggered a refresh, so a value the user was still typing in the inspector Width/Height box was reverted to the last saved one. Ruling: uncommitted local layout edits are tracked in a `draftRef` keyed by screen id, replayed over every fetched project, and cleared field-by-field once a save confirms them (`clearConfirmedFields` keeps edits a save did not carry). Cost if wrong: a refresh arriving mid-keystroke silently discards the user's input, which reads as the canvas "fighting" the user. Verified: `npm run typecheck` and `npm run build` pass.

2026-09-27 — test infrastructure and three latent e2e races: `vitest.config.ts` raised `testTimeout`/`hookTimeout` to 60s and capped `maxWorkers` at 4; `playwright.config.ts` raised `test` to 60s, `expect` to 15s, and set `workers: 2`. The 15s/5s defaults were tuned for in-process tests while these specs spawn a real server, a tsx CLI, and Chromium, so the suite failed on load rather than on a defect. Three e2e races were also fixed at the source: Select mode attaches the bridge only after an async nonce fetch, so a click issued before that was dropped (now the test waits for `?bridge=` on the frame src); `expect.poll` rethrows errors from its callback instead of retrying, so an iframe reload mid-`evaluate` failed the test (now returns a not-yet value); and the empty-workspace test created its project before the canvas SSE subscription was live, dropping the event (now waits for the `Connected` indicator).

Open, not yet resolved: the e2e suite is still intermittently flaky under heavy parallel load. The 15s/30s timeouts above were partly a symptom of running many suites back to back on an 8-core host, not only of a product defect — a stability run has to be measured on an otherwise idle machine before any further timeout is raised. Two orphaned runtime servers predating this session were observed (`~/local-canvas-demo` from 2026-09-26, a `/tmp/local-canvas-release-debug.*` workspace from 2026-09-25); neither was started by this session and both were left running for the owner to stop.
